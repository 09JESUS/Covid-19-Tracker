# Covid-19 Tracker Stats

A real-time COVID-19 tracking dashboard showing statistics using APIs, charts, and interactive visualizations.

## 🛠️ Technologies Used

![React](https://img.shields.io/badge/React-18-blue)
![Next.js](https://img.shields.io/badge/Next.js-14-black)
![Tailwind CSS](https://img.shields.io/badge/TailwindCSS-4.1.9-green)
![Recharts](https://img.shields.io/badge/Recharts-latest-orange)
![Zod](https://img.shields.io/badge/Zod-3.25.67-purple)

## Features

- Fetches live COVID-19 data from APIs  
- Interactive charts using Recharts  
- Dark/light mode with Tailwind CSS  
- Fully responsive and mobile-friendly  
- Input forms validated with React Hook Form & Zod
